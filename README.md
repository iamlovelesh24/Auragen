# AuraGen - WebSocket Telemetry Ingestion & Cognitive Load Engine`n`nReal-time backend telemetry ingestion server built with Node.js for AuraGen. It ingests live interaction events via WebSocket connections and dynamically calculates cognitive load scores.n`n## Project Overview`n`nThe WebSocket Telemetry Engine acts as the central ingestion hub for client-side interaction signals. It validates incoming telemetry payloads, tracks active connected clients, streams live score updates, and provides session reset capabilities.`n`n## Week 1 Implementation`n`nThe following features have been implemented and verified in this module:`n`n- **Real-Time WebSocket Ingestion Server (`server.js):** Listens on port 8080 to process client telemetry streams.n- **Sliding-Window Cognitive Load Calculator (`cognitiveLoad.js):** Computes live cognitive load metrics based on interaction duration, keypress delay, and activity frequency.n- **Payload Schema Validation & Active Client Tracking:** Rejects malformed JSON and logs connected client session IDs.`n- **End-to-End Test Client (`test-client.js):** Automated client script simulating live telemetry payloads and session resets.`n`n## Setup & Running Instructions`n`n1. **Install Dependencies:**`n   bash`n   npm install`n   `n`n2. **Start Ingestion Server:**`n   bash`n   node server.js`n   `n`n3. **Run End-to-End Test Verification:**`n   bash`n   node test-client.js`n   `
